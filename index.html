Seluruh bagian ujian di bawah ini dan menu kiri masih terkunci. Isi Nama Lengkap Peserta lalu klik tombol Start Test / Mulai Ujian untuk membuka akses dan memulai timer.

1. Navigasi Soal: Setelah ujian dimulai, klik nomor soal (1, 2, 3, dst.) atau nama section di sidebar kiri, maupun tombol Previous / Next di bagian bawah.

2. Bantuan Bahasa: Klik tombol Your Language 1 atau Your Language 2 di bawah kotak pertanyaan biru untuk melihat terjemahan kalimat soal.

3. Buat / Edit Soal Mandiri: Klik tombol hijau Buat / Edit Soal di pojok kanan atas untuk mengelola soal, mengatur timer per section, atau mengunduh file HTML ujian.
